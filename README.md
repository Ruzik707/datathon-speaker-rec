# Криптонит.Тембр — Speaker Recognition Datathon

Хакатонный ML-проект по распознаванию диктора по голосу.

Задача соревнования: для каждой тестовой аудиозаписи построить голосовое представление и найти наиболее похожие записи из тестового набора. Качество оценивалось метрикой **Precision@K**.

Проект реализован как компактный pipeline для извлечения аудиоэмбеддингов, поиска ближайших соседей и формирования `submission.csv`.

---

## Мой вклад

В рамках команды я занимался разбором задачи, построением собственного baseline-подхода и анализом пайплайна распознавания диктора.

Что было сделано:

- разобрал постановку задачи speaker recognition / speaker retrieval;
- реализовал компактный inference pipeline на базе pretrained `SpeechBrain ECAPA-TDNN`;
- извлекал аудиоэмбеддинги фиксированной размерности для `.flac` файлов;
- сравнивал эмбеддинги через cosine similarity / nearest-neighbour search;
- формировал `submission.csv` в формате соревнования;
- экспериментировал с линейной головой поверх эмбеддингов и шумовыми аугментациями;
- анализировал ограничения подхода и влияние выбора pretrained backbone.

---

## Подход

Основная идея решения:

1. Загрузить pretrained speaker encoder `speechbrain/spkrec-ecapa-voxceleb`.
2. Преобразовать каждую аудиозапись в эмбеддинг.
3. Нормализовать / сравнить эмбеддинги между собой.
4. Для каждой записи выбрать top-K ближайших соседей.
5. Сохранить результат в `submission.csv`.
